Shared Markdown scratchpads for coding-agent workstreams — with attached sessions,
claims, activity, revision-safe edits, and durable Repository Facts. Claude Code,
Codex, OpenCode, Pi, and ordinary terminals share one local SQLite commons.

<StatusDemo />

```sh frame="none" wrap
curl -fsSL https://raw.githubusercontent.com/sean35mm/weaver/main/install.sh | sh
```

One self-contained binary for macOS and Linux — no Node, coordination daemon,
cloud account, or MCP server. Everything stays on your machine. Use the rich/source
scratchpad UI, a normal browser, headless URL, terminal commands, or `$EDITOR`.
