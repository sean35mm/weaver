## Install in one line

```sh
curl -fsSL https://raw.githubusercontent.com/sean35mm/weaver/main/install.sh | sh
```

A single self-contained binary — **no Node, no npm, no dependencies**. Keep it current with
`weaver upgrade`, remove it with `weaver uninstall`.

## Why Weaver?

When you run several coding agents on one codebase, they're blind to each other: different
tools, different sessions, different memories. They edit the same files, redo each other's
work, and share no picture of what's in flight. Weaver fixes that with a fast local CLI any
agent can call.

## Built for agents first

Weaver is a **CLI** on purpose — the one interface every harness can call without an MCP
server or protocol setup. The docs are written for agents too: see
[Using Weaver from an agent](/weaver/guides/using-from-an-agent/) and the machine-readable
[`/weaver/llms.txt`](/weaver/llms.txt).
